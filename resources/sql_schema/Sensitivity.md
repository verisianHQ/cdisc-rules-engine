## Dataset

Report one result per dataset generated by the `Rule Type`, where a dataset or record within the dataset matches the rule failure criteria

## Record

Report one result per record within the dataset generated by the `Rule Type`, where the record matches the rule failure criteria

## Group

Report one result per unique combination of the values of the rule's `Grouping_Variables`, where a record in the group matches the rule failure criteria. Add `filter_by_dataset` to `Grouping_Variables` to only report groups found in the dataset being validated.

```yaml
Sensitivity: Group
Grouping_Variables:
  - USUBJID
  - VISITNUM
```

## Study

Report one result for the whole study, from the first dataset that matches the rule failure criteria
