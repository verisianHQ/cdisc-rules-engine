## Dataset

Report one result per dataset generated by the `Rule Type`, where a dataset or record within the dataset matches the rule failure criteria. The result shows the values of the first matching record. For a dataset split into several files, one result is reported for each file that has matching records.

## Record

Report one result per record within the dataset generated by the `Rule Type`, where the record matches the rule failure criteria. This is the default when the rule has no `Sensitivity`.

## Group

Report one result per group of records within the dataset generated by the `Rule Type`, where a record of the group matches the rule failure criteria. The groups are the combinations of values of the variables listed in the rule's top-level `Grouping_Variables`, and the first matching record of each group is reported. `--` in a grouping variable is replaced with the domain. Without `Grouping_Variables`, one result is reported per record, as for `Record`.

`filter_by_dataset` can be added to `Grouping_Variables` for rule types whose dataset holds the records of all datasets, such as `Global Value Check with Variable Metadata`: only records whose `dataset_name` is the dataset being validated are reported.

```yaml
Sensitivity: Group
Grouping_Variables:
  - --TESTCD
  - --STRESU
```

## Study

Report one result for the whole study. The datasets in scope are validated one at a time, and once a dataset reports a result, the remaining datasets are not validated. The result is reported as for `Dataset`. Use it for rule types whose dataset is the same whichever dataset is being validated, such as `Domain Presence Check` or `STF Metadata Check`.
